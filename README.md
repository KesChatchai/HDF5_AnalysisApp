# HDF5 Analysis App



MATLAB-based research applications for inspection of proton-transfer-reaction time-of-flight mass spectrometry (PTR-ToF-MS) data set



> \*\*Release preparation: Version 1.0\*\* 

## Overview

This application is designed to examine the ion intensity distribution of a selected ion.

The neighbouring m/z range can be adjusted to cover a broader mass-to-charge ratio window,

allowing users to assess potential deviations between the experimentally measured and

theoretical m/z values of the target ion.



**Requirements**

* MATLAB: 2024b or 2025a
* Supported operating systems: **N/A**
* Supported input data format(s): **HDF5 layout**



## Installation

1. Install a compatible MATLAB release.
2. Download the tagged release or clone this repository.
3. Open the relevant `.mlapp` file using MATLAB App Designer, or run the documented launcher if provided.
4. Test the application using the provided example dataset before analysing experimental data.

```bash git clone https://github.com/REPLACE\_USERNAME/HDF5\_AnalysisApp.git```
